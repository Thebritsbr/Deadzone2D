EMAIL VERIFICATION SETUP
========================

1. Enable two-step verification on your Google account:
   https://myaccount.google.com/security

2. Create an App password:
   https://myaccount.google.com/apppasswords
   Use "Mail" as the app and "Windows Computer" as the device. Google
   will show a 16-character password (for example abcd efgh ijkl mnop).

3. Edit Config/Mail.json in the game folder:
   - Enabled: true
   - User: your real @gmail.com address (the one that receives codes)
   - Password: the App password (without spaces)
   - Host and Port: keep the defaults (smtp.gmail.com / 587)

4. Restart Deadzone2D. The 6-digit code is sent to your real Gmail
   during registration and local login.

When Enabled is false, the code is displayed on screen for local testing.
