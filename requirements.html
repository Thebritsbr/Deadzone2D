System Requirements

Deadzone2D is a lightweight 2D top-down shooter built with C# WinForms and GDI+. It does not use a game engine or a dedicated GPU. The installer is about 2.6 MB and the installed game folder is under 1 MB.

Minimum (playable)Windows PC

OS: Windows 10 64-bit (version 1903 or newer) or Windows 11.

Runtime: .NET 8 Desktop Runtime (Microsoft.WindowsDesktop.App 8.0). The installer does not bundle it; install it from Microsoft if it is missing.

CPU: Dual-core 1.6 GHz (Intel Core i3 / AMD Ryzen 3 or equivalent).

RAM: 2 GB.

Storage: 100 MB of free disk space (game files are under 1 MB; the installer is ~2.6 MB).

Graphics: Any display adapter that supports DirectX 11. Rendering is done by GDI+ on the CPU, so no dedicated video card is needed.

Display: 1280 x 720, 16:9.

Input: Keyboard and mouse.

RecommendedSmooth 2D

CPU: Quad-core 3.0 GHz (Intel Core i5 / AMD Ryzen 5 or better).

RAM: 4 GB or more.

Storage: 1 GB free on an SSD (leaves room for updates and local account data).

Display: 1920 x 1080 or higher.

Network: Broadband connection for online sign-in, friends, chat and matchmaking. Offline/local play needs no network.

Architecturex64

The game is built for Windows x64 with .NET 8 and uses WinForms/GDI+. The executable is Deadzone2DApp.exe and the installer is DeadzoneSetup_v4.6.2.exe. Installation requires administrator rights to write to Program Files.

Local data (accounts, chat, settings) is stored in %LOCALAPPDATA%\Deadzone2D and survives updates.

Online serverNode.js 20+

The public server runs at https://deadzone2d.onrender.com. It is a Node.js 20+ service using Express and WebSocket. The game connects automatically; no API key or URL configuration is needed.

For self-hosting, run npm install and npm start. The server listens on port 3000 by default (or the PORT environment variable) and stores data in data/server.json. The included render.yaml deploys a free Render web service.

Need help?Open an issue

If the game fails to start, make sure .NET 8 Desktop Runtime is installed and that you are running the x64 build on 64-bit Windows: github.com/Thebritsbr/Deadzone2D/issues.
