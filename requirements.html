System Requirements

Deadzone2D is a lightweight 2D top-down shooter built with C# WinForms and GDI+. It does not need a game engine or a dedicated graphics card.

Installation requirementsWindows PC

Operating system: Windows 10 (64-bit, version 1903 or newer) or Windows 11.

Runtime: .NET 8 Desktop Runtime (Microsoft.WindowsDesktop.App 8.0). The installer does not bundle the runtime; install it from Microsoft if it is missing.

Architecture: x64 (64-bit) recommended. The installer requires administrator privileges to write to Program Files.

Internet: required only for version checks, downloading updates, Google sign-in and email verification. The game itself runs offline.

Minimum requirementsPlayable

Processor: Dual-core 2.0 GHz (Intel Core i3 / AMD Ryzen 3 or equivalent).

Memory (RAM): 4 GB.

Storage: 500 MB of free disk space for the game and local account data.

Graphics: Integrated graphics with DirectX 11 support (Intel HD Graphics 4000 / AMD Radeon HD 7000 or newer).

Display: 1280 x 720 resolution, 16:9 aspect ratio.

Input: Keyboard and mouse.

Recommended requirementsSmooth

Processor: Quad-core 3.0 GHz (Intel Core i5 / AMD Ryzen 5 or better).

Memory (RAM): 8 GB or more.

Storage: 1 GB of free space on an SSD.

Graphics: Dedicated GPU with 1 GB VRAM (GTX 1050 / RX 570 or newer). Not required — rendering is handled by GDI+.

Display: 1920 x 1080 or higher.

Supported platformsx64

Deadzone2D is built for Windows x64. The executable is named Deadzone2DApp.exe and is installed by DeadzoneSetup_v3.7.exe. The game stores local data in %LOCALAPPDATA%\Deadzone2D so it survives updates.

Need help?Open an issue

If the game fails to start, make sure the .NET 8 Desktop Runtime is installed and that you are running the x64 build on a 64-bit Windows system: github.com/Thebritsbr/Deadzone2D/issues.
