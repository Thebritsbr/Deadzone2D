Game modes

How to install

  1. Download DeadzoneSetup_v4.6.7.exe above.
  2. Run the installer and choose the install folder.
  3. Launch Deadzone from the Start Menu or desktop shortcut.
  4. Sign in with your Gmail/local account or create a new one.
  5. Pick a mode, choose your squad size, and play.

Updates install automatically on game start — no manual reinstall needed.
